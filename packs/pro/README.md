# pro scenes

Three finished cinematic scenes, each one folder with its scene.json and the CC0 files it needs.

| Folder | What it is |
|---|---|
| `pastel-gallery` | a marble bust on a mint plinth in a peach and lilac gallery, the title fades in beside it |
| `toy-showroom` | a vintage cine camera turning on a pink stage in a blue and yellow toy world |
| `sunset-flythrough` | the camera flies past a boombox, a pocket watch and a chess set on a desert at dusk, a glass plaque at each stop |

Make one:

```bash
npx github:wonseokjung/connect-ai-three make packs/pro/toy-showroom --short
```

Models and HDRIs are from Poly Haven (CC0). Each HDRI's source is in its `.meta.json`.
