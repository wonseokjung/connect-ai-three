How it works

One spec. Two outputs. A self-check.

It does not invent one more 3D library. It puts the three.js ecosystem behind one small file, and adds the check that code-made scenes usually skip.

01 · Say it

Plain words

Tell your coding agent what you want to see. The skill teaches it the spec and the whole catalog, so it writes scene.json instead of raw three.js.

02 · One spec

scene.json

Look, camera, lights, objects, motion, finish. Everything moves from time alone, so the page and the video are the same picture frame for frame.

03 · Checked

Then two outputs

The scene is built in a headless browser and measured first. Only then: an interactive page in one file, and a video (also transparent, also 9:16).

Run it

Three lines to your own scene.

Node 18 or newer. Works with Claude Code, Codex, Cursor and Antigravity, or with no agent at all.

npx connect-ai-three
Makes the demo scene and opens it in your browser.
npx connect-ai-three install
Adds the skill to your coding agent. Then just say what you want to see.
npx connect-ai-three make my-scene --short
Self-check, web page, video, a 9:16 version, still sheet and report.
